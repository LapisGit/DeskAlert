# DeskAlert

Cross-platform application to receive severe weather alerts on your desktop.

Made with C# and Qt 6.

</div>

# Features
- US Support with the NWS
- Canada support with the ECCC
- Plugin support (coming soon)
- Cross-platform (Linux and Windows)

# Development

## Prerequisites

1. .NET 8 (https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
2. Qt 6 for Development (https://www.qt.io/development/qt-framework/qt6)

## Local build instructions

1. Clone the repository:

```
git clone https://github.com/LapisGit/DeskAlert.git
cd DeskAlert
```

2. Set your Qt for Development path in the .csproj

3. Build the app.

```
dotnet build
```

4. Run the app.

```
dotnet run
```
