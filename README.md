# DeskAlert

Cross-platform application to receive severe weather alerts on your desktop.

Made with C# and Qt 6.

</div>

# Features
- US Support with the NWS
- Canada support with the ECCC
- Plugin support (coming soon)
- Cross-platform (Linux and Windows)
